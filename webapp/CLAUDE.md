# webapp/ — MealPlan+ PWA

Next.js 14 (App Router) · TypeScript · serwist service worker (PWA/offline). This IS the iPhone client
(runs in Safari). Deployed to Vercel: `https://mealplan-plus.vercel.app`.

## Commands
- Dev: `npm run dev`
- Build + lint (run before done): `npm run build && npm run lint`
- Regenerate API types from the backend contract: `npm run gen:api` (reads `../docs/openapi.yaml` → `lib/api/types.generated.ts`)

## Hard rules — never break
1. **Auth guard is client-side** in `(app)/layout.tsx` via Firebase — there is no edge middleware. Do not add edge/middleware auth.
2. **API types are generated, not hand-written.** IMPORTANT: after any backend contract change, run `npm run gen:api`; never hand-edit `lib/api/types.generated.ts`.
3. Firebase = Auth only on the client (root zero-billing rule).
4. Keep it offline-first: don't break the serwist service worker / PWA install.

## Deploy
Vercel auto-deploys on push to `main` (native GitHub integration). Env: `webapp/.env.local` (gitignored) — never commit secrets.

## Out of scope / do not touch
- `lib/api/types.generated.ts` — regenerated by `npm run gen:api`.
- `.next/`, `out/` — build output.
